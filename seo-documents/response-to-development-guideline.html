Each bullet from the guide, with what was done and how, or why not.

01 JavaScript-dependent content

  • Done
    Serve all main content in the initial HTML. The build now opens each of the 16 pages in a headless browser and saves the rendered page as its own HTML file. Tested with JavaScript switched off: the pages read in full.
  • Done
    Title, meta description, canonical, H1, body copy, images and internal links in the raw HTML. All present on every page; checked by script on all 16.
  • Done
    Internal links as standard anchors. They already were; confirmed.
  • Done
    JavaScript enhances but is not required. The sliders and animations still run; the content does not depend on them.

Note: the staging site still carries a noindex tag and blocks crawlers, on purpose, so the staging copy never competes with the live domain. The live build removes both.

09 Contact Us: Google Map

  • Done
    Map embedded beside the address, phone, email and form. Lazy-loaded, titled, responsive.
  • Done
    Pinned to the listing. The embed looks the business up by name and address and shows the listing's pin. If you would rather it used the Business Profile's own embed link (Share, then Embed a map), send the link and it goes straight in.
  • Done
    "How did you hear about us?" as a required dropdown. Five options rather than three: Google search, Google ad, Referral from a friend, builder or tradie, Facebook / Instagram / LinkedIn, Somewhere else. Customers do not recognise "Google Organic", and a required field with only three options forces wrong answers. The answer is sent to the CRM with every enquiry, alongside the automatic campaign and referrer capture the site already does.

10 Typography

  • Done
    Heading sizes reduced to the recommended scale. Measured on the site: desktop H1 56px, H2 40px, H3 24px, FAQ questions 20px, labels 13px; phone H1 32px, H2 26px, FAQ questions 16px. Line heights 1.1, 1.15 and 1.25.
  • Done
    Collapsed word spacing fixed. Tracking capped at -0.02em on every heading size and word spacing opened, so "What is R-Value?" reads as three words.
  • Done
    Scale defined as CSS variables, with fluid clamp() sizing.
  • Done
    One H1 per page, heading levels in order. Checked by script on all 16 pages.
  • Not done
    H1 and H2 at Bold weight. The display face is set at semibold across the site. Bold would change the brand look for a difference few readers would notice, and would add another font file. Easy to change if it matters to you.

How it was checked

Every page's raw HTML was checked by script for one H1, ordered headings, a description, a canonical, the menu links and the structured data. In a browser, the Services menu was driven by mouse and keyboard, the FAQ accordions opened and closed, the carousel timed, every visible text element measured for contrast, the contact form submitted with the source field empty, the gallery filters exercised, and eight pages loaded at 375, 390 and 414px. The Residential page was also loaded with JavaScript disabled to confirm it reads in full.

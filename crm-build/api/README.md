# Platform API catalogue (v2)

File: `platform-api-endpoints.json`. Every v2 endpoint of the platform's public API, grouped, with method, path,
summary, scopes, path and query params, key body fields (a trailing * means required), Hub relevance and our test
status. Base URL is the placeholder {BASE_URL}. Auth: Bearer integration token plus a Version header, location scoped.

## How it was made (30 Oct 2026)
Generated by script from the official public API docs and OpenAPI specs (v2 set, one spec per product area). No live
API call was made and no token was used. Hub relevance is our judgement by path. Our status comes from the probe
scripts step16 to step20 and HUB-NOTES.md. Anything not in those is "untested", even if documented.

## The 15 most useful endpoints for the Hub
1. GET /opportunities/pipelines : pipelines with their stages and IDs (tested).
2. POST /opportunities/ : create a job (tested).
3. PUT /opportunities/{id} : move stage, set value, owner, custom fields (tested).
4. PUT /opportunities/{id}/status : won, lost, open (tested).
5. POST /opportunities/search : filtered job lists for the board (untested; GET search tested).
6. POST /contacts/upsert : create or match a contact without duplicates (untested).
7. PUT /contacts/{contactId} : edit contact details (untested).
8. POST /contacts/{contactId}/tags and DELETE (tested).
9. POST /contacts/{contactId}/notes : write job notes onto the contact (untested).
10. POST /contacts/{contactId}/tasks : create follow-up tasks (untested).
11. POST /associations/relations : link extra contacts and company to a job (tested).
12. GET /associations/relations/{recordId} : read the links back (tested).
13. POST /conversations/messages : send SMS or email to extra contacts (untested).
14. GET /conversations/{conversationId}/messages : show history in the Hub (untested).
15. POST /calendars/events/appointments : book site visits (untested); also POST /invoices/ for drafts (untested).

## Blocked or unknown
- Workflows: only the list call exists in the spec; create, edit and read steps return 403 "not enabled for location"
  (vendor private beta, vendor support says it cannot be enabled). Retest with step16 now and then.
- Webhook subscriptions are not endpoints in the spec. They are set up in the platform app or per marketplace app.
  The event names below come from the platform's webhook event list and need checking in Dev before relying on them.
- Never tested: notes, tasks, appointments, conversation sends, invoice create, contact update and upsert,
  opportunity upsert and POST search, followers, bulk calls.
- Rate limits and burst caps are not in the specs. Check response headers during the first real test.

## Webhook events worth listening to for the Hub
- Opportunity: OpportunityCreate, OpportunityUpdate, OpportunityDelete, OpportunityStageUpdate, OpportunityStatusUpdate,
  OpportunityMonetaryValueUpdate, OpportunityAssignedToUpdate (keep the board in sync when staff move cards).
- Contact: ContactCreate, ContactUpdate, ContactDelete, ContactTagUpdate.
- Notes and tasks: NoteCreate, NoteUpdate, NoteDelete, TaskCreate, TaskComplete, TaskDelete.
- Messages: InboundMessage, OutboundMessage (customer replies on a quote).
- Appointments: AppointmentCreate, AppointmentUpdate, AppointmentDelete.
- Invoices: InvoiceCreate, InvoiceUpdate, InvoicePaid, InvoiceSent, InvoiceVoid.

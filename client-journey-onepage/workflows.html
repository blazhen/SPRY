Conventions that apply to every workflow

Stop on reply

Every sales sequence checks for an inbound reply before each send and stops if one has arrived. WF-34 handles the pause; each sequence still needs its own exit condition so a resumed contact does not receive a stale message. Reminders about an agreed date keep running.

Send window

Anything marked "waits for the send window" sits behind a Wait until a time window step: 8am to 8pm, Monday to Saturday. Confirmations are exempt.

Acceptance kills sales

WF-14 stops every sales sequence before it does anything else. Test this one specifically: accept a quote mid-follow-up and confirm nothing further sends.

Add-on quotes

WF-12 checks is-active-job before it moves anything. An accepted add-on or variation quote on a live job updates the value and tasks the office; it never resends the thank-you or moves the card.

Book in the platform first

Install dates are booked in the platform, in the calendar for the vehicle doing the job, never straight into the Apple calendar, because WF-20 is what moves the card and starts the reminders and the deposit draft. Two-way iCloud sync is a separate task.

Invoices are drafts

WF-24 and WF-27 create deposit and final invoices as drafts with a task to the owner. WF-25 and WF-28 run only when the owner sends them, so reminders never start on an invoice nobody has sent. Automate the send only when Glenn asks.

Alerts follow the role

Anything to the office goes by email and in-app, never SMS. Anything to the owner goes by SMS and email. WF-38 sends alert 14 on a hand-over, and skips it when another alert has just told the owner the same thing.

Error branches

Every workflow gets an error branch that fires alert 11 with the workflow name and the contact. A silent failure is a lead vanishing.

Human labels

Dropdown fields store the label, not the form value, or the echo emails read "new-build". Fixed once in WF-01, checked in the go-live list.

Required fields on entry

Stages that need a field to send correctly (callback time, inspection date, install date, deposit amount and foam order type, photos captured, invoice number, retention amount and release date) require it on the stage change rather than reminding afterwards.
